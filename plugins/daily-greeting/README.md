# Daily Greeting 插件

定时在 QQ 群发送问候消息，以及上下线通知。

## 定时任务

| 时间 | 消息 |
| ---- | ---- |
| 08:00 | 早上好！ |
| 14:00 | 𝓖𝓸𝓸𝓭 𝓪𝓯𝓽𝓮𝓻𝓷𝓸𝓸𝓷 |
| 20:00 | 下班！ |

## 事件通知

| 事件 | 消息 |
| ---- | ---- |
| 上线 | 我上线了 |
| 下线 | 下了 |

## 项目结构

```
plugins/daily-greeting/
├── Cargo.toml
└── src/
    ├── lib.rs      # 插件主入口，注册 cron 定时任务与事件回调
    └── config.rs   # 配置加载
```

## 配置项

在 `config.toml` 中需要配置以下节：

```toml
[daily_greeting]
group_id = "123456789"
```

| 字段 | 说明 |
| ---- | ---- |
| `group_id` | 发送消息的目标 QQ 群号 |
