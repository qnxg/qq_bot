# Welcome 插件

监听群成员增加事件，在新成员入群时自动 @ 该成员并发送欢迎消息。

## 工作流程

```
group_increase 通知 → 判断群号是否启用 → 按模板生成欢迎消息 → 发送到群
```

- 仅处理 `group_increase` 通知；被邀请入群和主动申请入群都会触发
- 机器人自己被拉进群时不会发送欢迎消息
- 欢迎消息中的 `{at}` 会被替换为 @新成员；如果模板中没有 `{at}`，会自动在消息开头 @新成员

## 配置项

在 `config.toml` 的 `[welcome]` 节配置：

```toml
[welcome]
# 启用入群欢迎的群号列表，空列表表示不启用
group_ids = ["123456789", "987654321"]
# 欢迎文本，{at} 会被替换为 @新成员
text = "{at} 欢迎来到湖大反考研/反保研/反本科搞科研/反升学/反计拔群"
```

| 字段 | 说明 |
| ---- | ---- |
| `group_ids` | 启用入群欢迎的群号列表（字符串） |
| `text` | 欢迎文本模板，可使用 `{at}` 占位符；不填写或留空时使用默认文本 |

默认文本为：

```text
{at} 欢迎来到湖大反考研/反保研/反本科搞科研/反升学/反计拔群
```

即发送时实际效果为：`@新成员 欢迎来到湖大反考研/反保研/反本科搞科研/反升学/反计拔群`。
