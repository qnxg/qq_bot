# Chat Logger 插件

收集指定 QQ 群的聊天记录（尽可能详尽，包含图片与文件）并存入全项目共享数据库 `local.db`。

## 工作流程

```
收到群消息   → 是否管理指令？→ 是：执行 监听/取消监听/统计监听
                          ↘ 否：群是否被监听？→ 是：落库 + 下载图片/文件到本地
收到文件上传通知 → 群是否被监听？→ 是：下载文件到本地 + 落库
```

- 管理指令需 **管理员 @ 机器人** 才会响应
- 消息收集对所有被监听的群自动生效，无需 @ 机器人

## 指令（仅管理员）

| 指令 | 用法 | 说明 |
| ---- | ---- | ---- |
| 监听 | `监听 <群号>` | 将群号加入监听列表，开始收集该群聊天记录 |
| 取消监听 | `取消监听 <群号>` | 将群号从监听列表移除 |
| 统计监听 | `统计监听` | 查看所有被监听群及其已收集的记录数量 |

## 数据表

启动时由项目根目录的 `init.sql` 自动创建：

- `monitored_groups`：被监听的群列表
- `chat_records`：群聊天记录，包含消息内容、时间、发送者（QQ 号 / 昵称 / 群名片 / 角色）、
  群号、原始消息串、纯文本、人类可读文本、图片信息、文件信息、完整消息段 JSON、完整原始事件 JSON 等

## 图片与文件下载

- **图片**：消息中的图片下载到 `image_dir/<群号>/` 下，`chat_records.images` 以 JSON 数组
  记录每张图片的原始 URL 与本地路径。
- **文件**：文件下载到 `file_dir/<群号>/` 下，`chat_records.files` 以 JSON 数组记录文件名、
  file_id、大小、下载 URL 与本地路径。

  群文件在 OneBot 协议中通常以 `group_upload` 通知事件出现（而非消息段），插件对两种来源都做处理。
  若通知/消息段未直接携带下载地址，会通过 OneBot 的 `get_group_file_url` 接口解析后再下载。

## 配置项

在 `config.toml` 的 `[chat_logger]` 节配置：

```toml
[chat_logger]
# 管理员 QQ 号列表，只有管理员 @ 机器人才能使用 监听/取消监听/统计监听 指令
admin_qq = [""]
# 聊天记录中图片下载保存的目录
image_dir = "data/chat_images"
# 聊天记录中文件下载保存的目录
file_dir = "data/chat_files"
```

数据库连接复用 `[database]` 节配置（见 `libs/data-client`）。
